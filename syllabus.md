# Python Learning Plan — General Foundation

**Interpreter:** Python 3.9.6 (`/usr/bin/python3`)
**Style:** Short lesson + quiz. You type every line by hand in VSCode and run it; I review before we move on.

## How each session works

1. I teach one concept with small, runnable examples.
2. I give you 3–4 quiz tasks. You create the files, type the code yourself (no copy-paste), run them, and fix your own errors.
3. You send me your code + terminal output. I grade it, point out habits to fix, then we continue.

## Rules

- Type everything yourself — muscle memory is the point.
- Run every file. Read the error message before asking me.
- Stuck for more than 5 minutes? Ask me, and include the exact error text.
- Never look up a solution before trying. Wrong attempts teach more than perfect copies.

## Roadmap

| # | Topic | You'll be able to... |
|---|-------|----------------------|
| 1 | print, comments, variables, types, arithmetic | Run a script and store/print data |
| 2 | input, strings, f-strings | Talk to the user; format text |
| 3 | Conditionals (if / elif / else) | Make programs decide things |
| 4 | Loops (for, while) | Repeat work without repeating code |
| 5 | Lists and tuples | Store collections of values |
| 6 | Dictionaries and sets | Store key → value data |
| 7 | Functions | Package code into reusable blocks |
| 8 | Errors and debugging (try/except) | Handle crashes gracefully |
| 9 | Files (read/write) | Persist data between runs |
| 10 | Modules and the standard library | Use `random`, `math`, `datetime` |
| 11 | Classes and objects | Model things in your programs |
| 12 | Comprehensions and built-ins | Write cleaner, shorter code |
| 13 | CSV and JSON | Work with real data files |
| 14 | Virtual environments and pip | Install third-party packages |
| 15 | Small project (part 1) | Apply everything to a real program |
| 16 | Small project (part 2) | Finish, polish, and ship it |

> Python 3.9 is fine for everything through Lesson 12. Before Lesson 14 we'll install a newer version via Homebrew so packages behave nicely — I'll walk you through it then.
